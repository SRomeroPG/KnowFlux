# Process Decisions (ADRs)

An ADR here records a durable decision about how the project operates: team structure, protocol, roadmap shape, audit rubric. Spec semantics are decided in the errata, not here.

- Files: `ADR-NNNN.md`, four-digit sequence, never renumbered or reused.
- Format: Title, Status (Accepted or Superseded, with date), Context, Decision, Consequences. About 40 lines at most.
- A decision changes only through a new ADR that supersedes the old one; the old file stays, marked `Superseded by ADR-NNNN`.
- Semantic gaps in the frozen spec go to `spec-gaps/SG-xxxx.md` and are decided in `knowledge-framework-spec-v2.1-errata.md`.
